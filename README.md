# Финальная викторина

Веб-викторина в стиле «Своей игры»: пять категорий, вопросы по 100–500 очков, две команды.

## Запуск

Открой index.html в браузере.

## Файлы

- index.html — структура страницы
- styles/main.css — оформление
- scripts/content.js — категории, вопросы, ответы, модификаторы и фото
- scripts/app.js — логика викторины
- images/ — фотографии к вопросам

## Модификатор «Ставка вслепую»

Стоит на вопросе про Фазмофобию. На доске клетка выглядит как обычная. После клика команда сначала делает ставку и только потом видит вопрос. Верный ответ приносит ставку, ошибка её отнимает.

Чтобы поставить ставку на другой вопрос, перенеси в него блок:

    modifier: { type: "bet", title: "Ставка вслепую", description: "...", minBet: 100 }

## Финальная игра

Кнопка «Начать финальную игру» внизу доски. Ведущий выбирает команду, дальше вопросы идут по одному. После кнопки «Показать варианты» появляются ответы со своей ценой, игрок выбирает один, и очки уходят его команде. Пока не нажата кнопка «Следующий вопрос», выбор можно поменять. После последнего вопроса открываются итоги.

Вопросы лежат в scripts/content.js, в разделе finalGame:

    {
        question: "Текст вопроса",
        options: [
            { text: "Вариант 1", points: 100 },
            { text: "Вариант 2", points: 300 },
            { text: "Вариант 3", points: 50 },
            { text: "Вариант 4", points: 500 }
        ]
    }

Цена может быть и отрицательной, например points: -100.

## Фото

Положи картинку в папку images и укажи путь в вопросе:

- `image: "images/файл.jpg"` — фото показывается вместе с вопросом
- `answerImage: "images/файл.jpg"` — фото появляется вместе с ответом

Имена файлов лучше писать латиницей без пробелов. На GitHub Pages важен регистр букв: Pikachu.JPG и pikachu.jpg для него разные файлы.

## Сохранение и сброс

Счёт и сыгранные вопросы хранятся в localStorage браузера. Чтобы начать с нуля, нажми «Начать заново».
